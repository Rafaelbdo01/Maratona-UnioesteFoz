# Maratona-Unioeste

Repositório destinado ao armazenamento das minhas soluções de problemas da programação competitiva.

## Plataformas

- Codeforces
- AtCoder
- USACO
- CSES

## Estrutura

### Codeforces

Problemas resolvidos do Problemset e contests realizados.

### AtCoder

Contests realizados.

### USACO

Problemas organizados principalmente pelas técnicas utilizadas na solução.

### CSES

Problemas organizados de acordo com as categorias da plataforma.
